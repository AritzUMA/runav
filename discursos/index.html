Parte I: Fundamentos de R y del entorno de trabajo

Qué es R

R es un lenguaje de programación estadístico diseñado específicamente para el análisis de datos, la estadística y la visualización. A diferencia de Excel, R es reproducible, extensible y gratuito. Los análisis se expresan como código: eso significa que cualquier colega puede replicar exactamente lo que has hecho.

En lingüística, R se usa para análisis de corpus, estadística de frecuencias, modelado de variación lingüística y visualización de patrones en el lenguaje.

R y RStudio

Son dos cosas distintas pero complementarias:

  • R es el motor: el lenguaje que interpreta y ejecuta el código.
  • RStudio es el entorno: la interfaz que facilita trabajar con R.

La analogía habitual es que R es el motor del coche y RStudio es el salpicadero.

El entorno de trabajo en RStudio

RStudio se organiza en cuatro paneles:

Panel Ubicación Para qué sirve
Script Arriba izquierda Escribir y guardar el código
Console Abajo izquierda Ver resultados y ejecutar líneas sueltas
Environment Arriba derecha Ver los objetos creados en la sesión
Files / Plots / Packages Abajo derecha Gestionar archivos y ver gráficos

R como calculadora

La forma más directa de empezar: R evalúa expresiones y devuelve resultados inmediatamente.

Parte II: Estructuras de datos y manipulación básica

Vectores

Un vector es una colección ordenada de elementos del mismo tipo. Es el bloque fundamental de R: casi todo en R es un vector. Se crean con la función c() (combine).

# Vector de longitudes de palabras
longitudes <- c(3, 5, 2, 8, 4, 6, 3, 7)

mean(longitudes)
[1] 4.75
median(longitudes)
[1] 4.5
max(longitudes)
[1] 8
length(longitudes)
[1] 8
# Vector de texto
palabras <- c("casa", "árbol", "luz", "universidad")
nchar(palabras)   # número de caracteres de cada palabra
[1]  4  5  3 11

Data frames

Un data frame es una tabla: las filas son observaciones y las columnas son variables. Es la estructura más habitual para trabajar con datos en R. Piensa en él como en la hoja de anotación de un corpus: cada fila es una unidad (palabra, enunciado, texto) y cada columna es una propiedad anotada.

corpus <- data.frame(
  palabra    = c("casa", "árbol", "correr", "azul"),
  categoria  = c("sustantivo", "sustantivo", "verbo", "adjetivo"),
  silabas    = c(2, 2, 3, 2),
  frecuencia = c(8420, 3105, 5622, 4890)

Visualización con ggplot2

ggplot2 usa una gramática de gráficos: defines los datos, el mapeo estético (aes) y la geometría (geom_*). Cada capa se añade con +.

# Histograma de longitud de discursos
ggplot(discursos, aes(x = n_palabras)) +
  geom_histogram(bins = 20, fill = "#c8102e", color = "white") +
  labs(
    title = "Distribución de longitud de discursos",
    x     = "Número de palabras",
    y     = "Frecuencia"
  ) +
  theme_minimal()
# Gráfico de barras: discursos por orador
discursos |>
  count(orador) |>
  ggplot(aes(x = reorder(orador, n), y = n, fill = orador)) +
  geom_col() +
  coord_flip() +
  labs(title = "Discursos por orador", x = NULL, y = "N") +
  theme_minimal() +
  theme(legend.position = "none")

## Parte I: Fundamentos de R y del entorno de trabajo {#parte-i}

### Qué es R

R es un lenguaje de programación estadístico diseñado específicamente para el análisis de datos, la estadística y la visualización. A diferencia de Excel, R es reproducible, extensible y gratuito. Los análisis se expresan como código: eso significa que cualquier colega puede replicar exactamente lo que has hecho.

En lingüística, R se usa para análisis de corpus, estadística de frecuencias, modelado de variación lingüística y visualización de patrones en el lenguaje.

### R y RStudio

Son dos cosas distintas pero complementarias:

- **R** es el motor: el lenguaje que interpreta y ejecuta el código.
- **RStudio** es el entorno: la interfaz que facilita trabajar con R.

La analogía habitual es que R es el motor del coche y RStudio es el salpicadero.

### El entorno de trabajo en RStudio

RStudio se organiza en cuatro paneles:

| Panel | Ubicación | Para qué sirve |
|---|---|---|
| Script | Arriba izquierda | Escribir y guardar el código |
| Console | Abajo izquierda | Ver resultados y ejecutar líneas sueltas |
| Environment | Arriba derecha | Ver los objetos creados en la sesión |
| Files / Plots / Packages | Abajo derecha | Gestionar archivos y ver gráficos |

### R como calculadora

La forma más directa de empezar: R evalúa expresiones y devuelve resultados inmediatamente.

```{r}
2 + 3
10 / 4
2 ^ 8

```

También tiene funciones estadísticas básicas:

```{r}

```

## Parte II: Estructuras de datos y manipulación básica {#parte-ii}

### Vectores

Un vector es una colección ordenada de elementos del mismo tipo. Es el bloque fundamental de R: casi todo en R es un vector. Se crean con la función `c()` (*combine*).

```{r}
# Vector de longitudes de palabras
longitudes <- c(3, 5, 2, 8, 4, 6, 3, 7)

mean(longitudes)
median(longitudes)
max(longitudes)
length(longitudes)
```

```{r}
# Vector de texto
palabras <- c("casa", "árbol", "luz", "universidad")
nchar(palabras)   # número de caracteres de cada palabra
```

### Data frames

Un data frame es una tabla: las filas son observaciones y las columnas son variables. Es la estructura más habitual para trabajar con datos en R. Piensa en él como en la hoja de anotación de un corpus: cada fila es una unidad (palabra, enunciado, texto) y cada columna es una propiedad anotada.

```{r}
corpus <- data.frame(
  palabra    = c("casa", "árbol", "correr", "azul"),
  categoria  = c("sustantivo", "sustantivo", "verbo", "adjetivo"),
  silabas    = c(2, 2, 3, 2),
  frecuencia = c(8420, 3105, 5622, 4890)
)

corpus
```

### Exploración inicial

```{r}
str(corpus)       # estructura del objeto
summary(corpus)   # resumen estadístico
nrow(corpus)      # número de filas
ncol(corpus)      # número de columnas
```

### Acceso y selección de variables

```{r}
# Acceder a una columna con $
corpus$palabra
corpus$frecuencia

# Acceder por posición [fila, columna]
corpus[1, ]        # primera fila completa
corpus[, 2]        # segunda columna completa
corpus[2, 3]       # fila 2, columna 3
```

### Filtrado de observaciones

```{r}
corpus[corpus$silabas == 2, ]
corpus[corpus$frecuencia > 5000, ]
corpus[corpus$categoria == "sustantivo", ]
```

### Importación de datos externos

```{r}
#| eval: false
```

Para esta sesión trabajamos con un dataset de ejemplo que construimos directamente:

```{r}
set.seed(42)
discursos <- data.frame(
  orador     = rep(c("Orador A", "Orador B", "Orador C", "Orador D"), each = 15),
  partido    = rep(c("Partido 1", "Partido 2", "Partido 1", "Partido 2"), each = 15),
  anyo       = sample(2010:2023, 60, replace = TRUE),
  n_palabras = round(rnorm(60, mean = 600, sd = 150)),
  n_oraciones= round(rnorm(60, mean = 30, sd = 8))
)

glimpse(discursos)
```

### Manipulación con dplyr

`dplyr` ofrece verbos intuitivos para transformar datos. El operador `|>` (*pipe*) encadena operaciones de izquierda a derecha, como instrucciones en lenguaje natural.

```{r}
# select(): seleccionar columnas
discursos |> select(orador, anyo, n_palabras)
```

```{r}
# filter(): filtrar filas por condición
discursos |> filter(anyo >= 2018)
```

```{r}
# mutate(): crear nuevas variables
discursos |> mutate(palabras_por_oracion = n_palabras / n_oraciones)
```

```{r}
# Encadenando operaciones
discursos |>
  filter(anyo >= 2018) |>
  select(orador, partido, n_palabras) |>
  mutate(palabras_k = round(n_palabras / 1000, 2)) |>
  arrange(desc(n_palabras))
```

### Estadística descriptiva

```{r}
# Resumen global
discursos |>
  summarise(
    media_palabras   = mean(n_palabras),
    mediana_palabras = median(n_palabras),
    total_discursos  = n()
  )
```

```{r}
# Agrupado por partido
discursos |>
  group_by(partido) |>
  summarise(
    media  = round(mean(n_palabras), 1),
    n_disc = n()
  ) |>
  arrange(desc(media))
```

```{r}
# Frecuencias de una variable categórica
discursos |> count(orador, sort = TRUE)
```

### Visualización con ggplot2

`ggplot2` usa una gramática de gráficos: defines los datos, el mapeo estético (`aes`) y la geometría (`geom_*`). Cada capa se añade con `+`.

```{r}
# Histograma de longitud de discursos
ggplot(discursos, aes(x = n_palabras)) +
  geom_histogram(bins = 20, fill = "#c8102e", color = "white") +
  labs(
    title = "Distribución de longitud de discursos",
    x     = "Número de palabras",
    y     = "Frecuencia"
  ) +
  theme_minimal()
```

```{r}
# Gráfico de barras: discursos por orador
discursos |>
  count(orador) |>
  ggplot(aes(x = reorder(orador, n), y = n, fill = orador)) +
  geom_col() +
  coord_flip() +
  labs(title = "Discursos por orador", x = NULL, y = "N") +
  theme_minimal() +
  theme(legend.position = "none")
```

## Parte IV: Aplicación integrada {#parte-iv}

En esta parte integramos todo lo aprendido en un pipeline completo: importación, exploración, estadística y visualización, aplicado a un corpus de discursos políticos.

### Exploración del corpus

```{r}
summary(discursos)
```

### Estadísticas descriptivas por orador

```{r}
resumen <- discursos |>
  group_by(orador, partido) |>
  summarise(
    n_discursos     = n(),
    media_palabras  = round(mean(n_palabras), 1),
    media_oraciones = round(mean(n_oraciones), 1),
    ratio_pal_or    = round(mean(n_palabras / n_oraciones), 2),
    .groups = "drop"
  )

resumen
```

### Identificación de patrones en el lenguaje

Calculamos la complejidad oracional media (palabras por oración) como indicador del estilo discursivo de cada orador.

```{r}
resumen |>
  arrange(desc(ratio_pal_or)) |>
  select(orador, partido, ratio_pal_or)
```

### Representación gráfica de resultados

```{r}
ggplot(resumen,
       aes(x = reorder(orador, ratio_pal_or),
           y = ratio_pal_or,
           fill = partido)) +
  geom_col() +
  coord_flip() +
  labs(
    title    = "Complejidad oracional por orador",
    subtitle = "Ratio palabras / oración (media)",
    x        = NULL,
    y        = "Palabras por oración",
    fill     = "Partido"
  ) +
  theme_minimal(base_size = 13) +
  theme(legend.position = "bottom")
```

### Evolución temporal

```{r}
discursos |>
  group_by(anyo) |>
  summarise(media_longitud = mean(n_palabras), n = n()) |>
  ggplot(aes(x = anyo, y = media_longitud)) +
  geom_line(color = "#c8102e", linewidth = 1) +
  geom_point(color = "#c8102e", size = 2.5) +
  labs(
    title = "Evolución de la longitud media de discursos",
    x     = "Año",
    y     = "Palabras (media)"
  ) +
  theme_minimal()
```
